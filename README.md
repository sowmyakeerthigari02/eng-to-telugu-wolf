# English to Telugu wolf videos

The Claude Code chat used to dub English animated wolf-story reels into Telugu
(Telugu voice-over with IndicF5, Telugu subtitles, music kept from the source).

- `chat/conversation.md`: the conversation in readable form
- `chat/transcript_clean.jsonl`: the full transcript
- `chat/metadata.json`: session details

Embedded images were removed and secrets (access tokens) redacted before upload.
